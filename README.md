I use the following settings:

```jsonc
{
	"show_tab_close_buttons_on_left": true,
	"sidebar_on_right": true,
	"hide_tab_scrolling_buttons": true,
	"ui_separator": true,
}
```

`ui_separator` is a custom setting that comes from Ayu. Other custom settings from Ayu have been retained, but I haven't documented them.

I use Input Sans.
